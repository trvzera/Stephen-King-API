# Stephen King API — Treino

Atividade de treino em Dart para consumir uma API externa (Stephen King API), tratar o JSON da resposta e exibir os dados no console.

O código fica na pasta `apis`. Execute com `dart run` a partir dela para testar o programa e conferir as respostas das questões no `apis/README.md`.
